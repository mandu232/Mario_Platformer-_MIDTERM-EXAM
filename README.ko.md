# 마리오 2D 플랫폼 게임

Unity로 제작한 중간고사 프로젝트입니다.

## 조작 방법

| 동작 | 조작 키 |
| --- | --- |
| 이동 | A / D 또는 왼쪽 / 오른쪽 방향키 |
| 점프 | 스페이스바 — 길게 누르면 더 높이 점프 |
| 불꽃 발사 | 강화 상태에서 마우스 왼쪽 버튼 |
| 다음 스테이지로 이동 | 출구 문에 닿은 상태에서 위쪽 방향키 |
| 게임 오버 또는 최종 클리어 후 재시도 | R |


## 보스전

보스는 공중을 순찰하다가 회전한 뒤 플레이어를 향해 돌진합니다. 벽이나 바닥에 충돌하면 떨어져 기절합니다.

- 불꽃 꽃이 나옵니다.
- 보스가 지상에서 기절한 동안에만 불꽃 공격으로 피해를 줄 수 있습니다.
- 유효한 불꽃 공격을 10회 맞히면 보스를 처치합니다.


## 실행 방법

### Windows 빌드

1. 깃허브의 Build 다운 혹은 릴리스 버전을 다운로드 이후 `Build/MIDTERM EXAM.exe`를 실행합니다.

### Unity 에디터

1. Unity **6000.6.2f1**에서 프로젝트를 엽니다.
2. `Assets/Scenes/Stage1.unity`를 엽니다.
3. 플레이 모드를 실행하고 Game 뷰를 클릭해 키보드·마우스 입력을 활성화합니다.

`Assets/Scenes/Stage2.unity`를 열면 두 번째 스테이지를 바로 테스트할 수 있습니다.



## 중간고사 점검표

- [✔] **1. 강화 아이템: 플레이어 크기 20% 증가 및 불꽃 공격.**
- [✔] **2. 불꽃의 정상 이동 및 적·보스 명중.**
- [✔] **3. 비행 적의 비행·플레이어 감지·공격.**
- [✔] **4. 충돌 시 강화 해제 또는 체력·목숨 감소.** 
- [✔] **5. 체크포인트 활성화 및 부활 위치 저장.**
- [✔] **6. 사망 후 정상 부활.**
- [✔] **7. 목숨·코인·점수·타이머 HUD.** 
- [✔] **8. 180초 카운트다운.**
- [✔] **9. 보스의 지정 영역 순찰 및 공격.**
- [✔] **10. 공격 10회 명중 시 보스 처치.**
- [✔] **11. 게임 오버·스테이지 클리어 화면.**
